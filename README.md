# 末端执行器建模

机械臂末端执行器的 SolidWorks 零件 以及 装配文件。

## 本地目录对应关系

- 本仓库对应本地目录：`F:\SW\末端`

## 文件列表

**装配**

- `大末端执行器.SLDASM` — 末端执行器总装配
- `舵机.SLDASM` — 舵机装配

**零件**

- `末端执行器.SLDPRT` — 末端执行器主体
- `下端支架_wlj20251226.SLDPRT` — 下端支架
- `舵机支架小_wlj20251226.SLDPRT` — 舵机支架小
- `挡料盘_wlj20251226.SLDPRT` — 挡料盘
- `零件1.SLDPRT` ~ `零件5.SLDPRT` — 其余结构件

## 打开方式

使用 SolidWorks 打开 `.SLDASM` 装配，并保持本目录下零件文件完整，避免引用丢失。

- `.SLDPRT`：零件
- `.SLDASM`：装配
